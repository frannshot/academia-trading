# Academia de Trading EUR/USD

Curso completo desde cero: trading intradía del EUR/USD, economía, bolsa, criptomonedas y derivados, organizado en semestres con exámenes, más un simulador de backtesting y un diario.

- App web instalable (PWA): en el iPhone, Safari → Compartir → *Agregar a pantalla de inicio*.
- **Con cuenta** (correo y contraseña): el progreso se sincroniza en todos tus dispositivos. Cada persona solo puede ver sus propios datos.
- **Sin cuenta**: el progreso se guarda en el dispositivo.
- Para publicar una versión nueva se cambia `VERSION` en `sw.js`.

Material educativo. No es asesoría financiera.
